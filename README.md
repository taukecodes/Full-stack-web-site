# Kalo & Crumb — Specialty Coffee Roastery & Brewing Gear

A modern, editorial-style web application built for **Kalo & Crumb**, an independent specialty coffee roastery and brewing equipment store. Designed with a tactile, warm aesthetic, smooth micro-interactions, and an end-to-end interactive shopping experience.

## Key Features

- **Editorial & Tactile UI:** Warm off-white (`#F7F4EE`) and deep espresso (`#1A1715`) color palette paired with clean typography and `1px` hairline borders.
- **Interactive Product Catalog:** Filter products by category (*All*, *Single Origin*, *Espresso Blends*, *Pour-Over Gear*) with tasting notes and roast origin tags.
- **Product Quick-View & Grind Selector:** Select grind preferences (*Whole Bean*, *Pour-Over*, *Espresso*, *French Press*) before adding items to the bag.
- **Slide-Over Shopping Bag Drawer:** Real-time cart updates, quantity adjustments, item removal, live subtotal calculation, and a free-shipping progress bar.
- **Infinite Review Marquee:** Smooth horizontal scrolling customer reviews with pause-on-hover functionality and `prefers-reduced-motion` accessibility support.
- **Interactive Brew Guide:** Step-by-step brewing ratios and methods (*V60*, *French Press*, *Espresso*) with interactive tabs.
- **Fully Responsive:** Optimized for desktop, tablet, and mobile devices.
